# F.o.A.-Tools (FOA-Tools)

**DE:** Freeware-Werkzeuge für Adventure Game Studio (AGS) 3.6.2: der **Manager** als Schaltzentrale, der **Raum- / Szenen-Editor** und **Dev-Tool Lite** mit dem Live-Fenster fürs laufende Debug-Spiel.
**EN:** Freeware tools for Adventure Game Studio (AGS) 3.6.2: the **Manager** as control center, the **Room / Scene Editor** and **Dev-Tool Lite** with the live window for the running debug game.

> **Beta / Vorabversion:** F.o.A.-Tools befindet sich in der Beta. Die aktuellen Versionen sind auf GitHub als *Pre-release* gekennzeichnet. Bitte sichere dein AGS-Projekt vollständig, bevor du Werkzeuge einsetzt.
> **Beta / pre-release:** F.o.A.-Tools is in beta. Current versions are marked as *pre-release* on GitHub. Please make a complete backup of your AGS project before using any tool.

## Was ist dabei? / What is included?

| Werkzeug / Tool | Wofür / What for |
|---|---|
| **Manager** | Projekt und AGS wählen, Werkzeuge installieren und entfernen, Projekt-Backups, Updates / choose project and AGS, install and remove tools, project backups, updates |
| **Raum- / Szenen-Editor** (Room / Scene Editor) | Arbeit an Räumen und Szenen / work on rooms and scenes |
| **Dev-Tool Lite** (Live-Fenster / live window) | Lautstärke, Teleporter, Walk-Recorder, Kanäle, Soundquellen, Spielzustand und Werte ins Skript, neben dem laufenden Debug-Spiel / volume, teleporter, walk recorder, channels, sound sources, game state and values to script, next to the running debug game |

## Download

1. Öffne die **[Releases-Seite](https://github.com/followers-of-armageddon/FOA-Tools/releases)** und nimm die **oberste Version** in der Liste.
2. Lade die Datei `FOA_Tools_V…_Setup.zip` herunter (nicht den Quellcode-Download), entpacke sie **vollständig** und starte `INSTALL.cmd`.
3. Öffne den Manager, wähle dein AGS-Projekt und installiere **Dev-Tool Lite** und den **Editor** per Klick.
4. Updates findet der Manager selbst (alle 30 Minuten oder über "Updates suchen"). Updates sind signiert. Bei Dev-Tool Lite wird nach einem Update das Modul im Projekt automatisch aktualisiert, danach in AGS mit F5 neu kompilieren.

1. Open the **[Releases page](https://github.com/followers-of-armageddon/FOA-Tools/releases)** and take the **topmost version** in the list.
2. Download `FOA_Tools_V…_Setup.zip` (not the source code download), extract it **completely** and run `INSTALL.cmd`.
3. Open the Manager, choose your AGS project and install **Dev-Tool Lite** and the **editor** with a click.
4. The Manager finds updates by itself (every 30 minutes or via "Check for updates"). Updates are signed. For Dev-Tool Lite the module in the project is updated automatically after an update; then recompile in AGS with F5.

Hinweis: Die Markierung *Latest* auf GitHub zeigt noch eine ältere Version. Maßgeblich ist die oberste Vorabversion in der Liste. / Note: the *Latest* badge on GitHub still shows an older version. The topmost pre-release in the list is the current one.
