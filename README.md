# FOA-Tools

**DE:** Freeware-Werkzeuge für Adventure Game Studio (AGS) – FOA Manager, Raum-Editor und Cutscene-Editor.
**EN:** Freeware tools for Adventure Game Studio (AGS) – FOA Manager, Room Editor and Cutscene Editor.

## Download

Die aktuelle Version gibt es unter **[Releases](https://github.com/followers-of-armageddon/FOA-Tools/releases/latest)**.
ZIP entpacken und `INSTALLIEREN.cmd` starten. Den SHA-256-Wert findest du bei jedem Release.

Get the latest version from **[Releases](https://github.com/followers-of-armageddon/FOA-Tools/releases/latest)**.
Unzip and run `INSTALLIEREN.cmd`. The SHA-256 hash is listed with every release.
